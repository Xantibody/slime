# Build instructions (for AMO reviewers)

This extension is bundled with esbuild (no minification). The submitted
xpi contains the exact contents of the `dist/firefox/` directory produced by
the steps below.

## Requirements

- Node.js 22
- pnpm 12
- `zip`

`nix develop` provides all of them from `flake.nix`.

## Build

```sh
pnpm install --frozen-lockfile
VERSION=<version being reviewed> pnpm run build:firefox
```

`pnpm run build:firefox` runs `build/main.ts`, which calls esbuild and
copies the static files. It produces:

- `dist/firefox/inject.js` — bundled from `src/entrypoints/page.ts`
- `dist/firefox/content-script.js` — bundled from `src/entrypoints/content.ts`
- `dist/firefox/popup.js` — bundled from `src/entrypoints/popup/main.ts`
- `dist/firefox/background.js` — bundled from `src/entrypoints/background/firefox.ts`
- `dist/firefox/manifest.json` — generated by `build/manifest.ts`
- `dist/firefox/_locales/{en,ja}/messages.json` — generated from `build/locales.ts`, which holds the manifest's description in each language
- `dist/firefox/popup.html` — copied from `src/entrypoints/popup/index.html`
- `dist/firefox/options.js` — bundled from `src/entrypoints/options/main.ts`
- `dist/firefox/options.html` — copied from `src/entrypoints/options/index.html`
- `dist/firefox/icons/` — copied from `icons/`
- `dist/slime-firefox.xpi` — a zip of `dist/firefox/`

There are no runtime dependencies; everything in the bundles comes from
the TypeScript sources in `src/`.
