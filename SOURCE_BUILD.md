# Build instructions (for AMO reviewers)

This extension is bundled with esbuild (no minification). The submitted
xpi contains the exact contents of the `dist/firefox/` directory produced by
the steps below.

## Requirements

- Node.js 22
- pnpm 12
- `zip`

`nix develop` provides all of them from `flake.nix`.

## Build

```sh
pnpm install --frozen-lockfile
VERSION=<version being reviewed> pnpm run build:firefox
```

`pnpm run build:firefox` runs `scripts/build.ts`, which calls esbuild and
copies the static files. It produces:

- `dist/firefox/inject.js` — bundled from `src/inject.ts`
- `dist/firefox/content-script.js` — bundled from `src/content-script.ts`
- `dist/firefox/popup.js` — bundled from `src/popup.ts`
- `dist/firefox/background.js` — bundled from `src/background.firefox.ts`
- `dist/firefox/manifest.json` — generated by `src/build/manifest.ts`
- `dist/firefox/popup.html` — copied from `src/popup.html`
- `dist/firefox/icons/` — copied from `icons/`
- `dist/slite-ime-fix-firefox.xpi` — a zip of `dist/firefox/`

There are no runtime dependencies; everything in the bundles comes from
the TypeScript sources in `src/`.
